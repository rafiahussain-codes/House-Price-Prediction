# House Price Prediction

## Project Overview
Predicting house prices using Machine Learning.

## Dataset
Ames Housing Dataset from Kaggle.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Models
- Linear Regression
- Random Forest
- Gradient Boosting

## Model Performance

| Model | MAE | RMSE | R² |
|---|---:|---:|---:|
| Linear Regression | 24350 | 34230 | 0.788 |
| Random Forest | 16865 | 24283 | 0.893 |
| Gradient Boosting | 16343 | 22408 | 0.909 |

## Best Model
Gradient Boosting Regressor

## Conclusion
Gradient Boosting achieved the best performance with an R² score of approximately 0.91.
